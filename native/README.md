# CanvasShutter native

The desktop version of CanvasShutter, written in Rust. Work in progress; the
[online editor](https://jeaniususa.github.io/CanvasShutter/) is the version to use today.

## Run it
1. Install Rust from [rustup.rs](https://rustup.rs).
2. In this folder:
   ```
   cargo run
   ```
   The first build downloads and compiles the dependencies and takes a few minutes.
